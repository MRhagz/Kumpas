# SW-19 student and counselor report content

Kumpas presents student-safe career options, supported evidence, comparative scores, trade-offs, uncertainty and next steps before counselor detail. Both report audiences use the same assembled student projection.

The system excludes raw notes from printed student content, distinguishes self-reported interests from academic evidence and retains AI-assistance, counselor-responsibility and score-limit disclosures. Missing components keep null totals/ranks. Source references and absent/unreadable/unsupported document status remain available for counselor review.

The system preserves profile/run/report identity and immutable PDF generation/expiry metadata. PDF pages retain their Draft origin marking; exact-version counselor approval governs final download without rewriting the artifact.

The system passes complete Grade 10/SHS, partial, notes-only, long-title, multipage, missing-date, confidentiality, score and PDF-bounds checks. Student comprehension, counselor review and visual verification pass.
