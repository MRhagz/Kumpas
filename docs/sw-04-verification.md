# SW-04 notes and processing notice

Kumpas requires Career Goal and Personal Interests and Strengths. An undecided goal is valid. Financial context, concerns and overall impression are optional; blank values remain blank.

The system rejects required fields containing only markup, whitespace or invisible editor characters. Typed notes and prepared note photographs use the same editable five-field form. Notes-only intake does not require academic uploads.

The system presents the processing notice before upload and requires review of the exact notes before approval. Editing notes or switching input method revokes that confirmation. Photographed-note extraction requires the owned session and current notes revision.

The system passes all 28 notes API/client checks and the integrated intake regressions. Human processing-notice, school-contact and policy verification pass.
